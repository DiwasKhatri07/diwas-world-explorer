# Implementation Memory

## Chosen Experience

The site is a self-contained, full-screen personal discovery game. Players spawn as Diwas, travel around a tiny tropical island, and uncover placeholder profile information at four landmarks.

## Key Decisions

- The visual direction is **Postcard Archipelago**, documented in `ideas.md`.
- The world uses a fixed elevated third-person camera and intentionally avoids costly imported 3D models or physics.
- All profile data is intentionally dummy content and held client-side for easy replacement later.
- A `?demo` mode must place the UI into an illustrative, deterministic discovery state for screenshot verification.
