The site presents Diwas as a student and learner in Nepal who is currently learning Python Full Stack and Java. The public skills section mentions Python, Java, PHP, C++, HTML, and JavaScript, while the setup includes Android, Termux, Pydroid, VS Code, and Python 3.13.

### Content Intended for the Explorer World

The expanded map may turn these into a **Learner’s Workshop** and **Tool Camp** discovery path. The world can link to the public GitHub profile only after it is reviewed in the final content pass.

### Visual Notes

The source site uses dark blue/black glass panels and electric-blue technical accents. These can inform a separate “night lab” level, while the existing tropical expedition map remains the primary entry world.

The site positions Diwas Khatri as a Nepal-based developer, creator, and student focused on Python, AI, API design, web development, Java, and Lua. Its public work archive identifies four suitable project stations: **NEPSE API**, **BDIX IPTV**, **Magic Link**, and **Diwas PyPi**. ### Content Intended for the Explorer World

The expanded world can use a **Project Archive level** containing one route station for each named project, plus a **Night Lab level** for Python, AI, and Nepali LLM exploration. The public profile image and certificate are not automatically copied into the world; a player photo is used only if the user uploads or explicitly approves one. The user’s age, school, location detail, email address, and social links are intentionally excluded from the game content.

### Visual Notes

The second site has a black, editorial portfolio look with oversized display type and archival project headings. Its “core / arsenal / selected works” structure maps well to chapter names, a mission menu, and a multi-level project archive.

## Verified Project Detail: NEPSE API

The public NEPSE API README describes a Python/FastAPI unofficial developer API for Nepal Stock Exchange market information. It documents market status, today’s price, indices, top-performer, company, and floorsheet endpoints, plus a PyPI package and local API server workflow.

### Archive Treatment

The world will frame this as a **Data Observatory** project station: an engineering archive about designing developer tools for live market information. It will not surface, recommend, or interpret financial data, nor will it embed live investment information into the game.

The public GitHub profile lists **Automate YT Channel**, described as an authorized Python media workflow with ingest, rendering, metadata preparation, duplicate protection, and YouTube Data API uploads; and **Nepali IDE**, described as an AI-native Android code editor with Kotlin/Jetpack Compose, syntax highlighting, a built-in Python interpreter, HTML preview, workspace support, and Git integration.
